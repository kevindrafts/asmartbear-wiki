# Color Wheels are wrong? How color vision actually works

[Read Jason Cohen’s original](https://longform.asmartbear.com/color-wheels/) · Unofficial editorial note.

This non-business essay compares artists’ color wheels, printing inks, display pixels, physical wavelengths, and visual perception. Cohen’s explanatory model distinguishes additive and subtractive mixing, cone responses, opponent processing, and contextual illusions. The figures show why identical colors can look different in different surroundings.

**Apply it:** A reminder to ask what a model represents before treating it as physical reality. That business connection is editorial inference.

**Boundary:** Cohen explicitly calls the physiology highly simplified. One extracted diagram description also conflicts with the prose’s subtraction account, so this note avoids reproducing its equations and directs technical readers to the original references.
