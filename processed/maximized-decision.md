# Binstack: Making a maximal multi-dimensional decision

[Read Jason Cohen’s original](https://longform.asmartbear.com/maximized-decision/) · Unofficial editorial note.

Binstack replaces weighted scores with two explicit judgments: which outcomes matter most, and whether each option materially changes each outcome. Cohen first orders outcomes, then eliminates options that fail the highest priority and uses lower priorities to separate the survivors. The tables illustrate how arithmetic on uncertain, incomparable ratings can obscure those choices.

**Apply it:** Define observable materiality and basic feasibility requirements before ranking outcomes. Explain both the selected option and why attractive alternatives lost.

**Boundary:** This method seeks impact, not impact per unit cost. If nothing meets the threshold, generate better ideas; if suitable options remain tied, team enthusiasm can decide. It is not intended for every complex societal decision.
