# Ballad of The Lean Startup

[Read Jason Cohen’s original](https://longform.asmartbear.com/lean-startup-ballad/) · Unofficial editorial note.

This short poem celebrates Eric Ries's account of learning from customers at IMVU. Discarded code becomes useful progress when it exposes mistaken assumptions; activity alone is not evidence that a product is improving. The accompanying loop diagram connects building, measurement, and learning.

**Apply it:** State what a release should teach and which customer behavior would support or contradict the hypothesis.

**Boundary:** This is a humorous tribute to validated learning, not a complete description or independent evaluation of the Lean Startup method.
