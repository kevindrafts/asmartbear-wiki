# Moats: Durable competitive advantage

[Read Jason Cohen’s original](https://longform.asmartbear.com/moats/) · Unofficial editorial note.

Differentiation loses value when rivals can readily reproduce it. Cohen analyzes AWS as a historical example of several reinforcing defenses: scale-funded innovation, an ecosystem, accumulated operating experience, reputation, and switching costs. A taxonomy names possibilities, but strategy must explain the activities and resources that will actually create a selected advantage.

**Apply it:** Name the intended durable advantage, how it will form, and the costly or undesirable consequences the organization must accept while building it.

**Boundary:** The cloud comparisons and financial charts describe their source periods. Lock-in can protect a vendor while burdening customers; merely declaring switching costs or citing a moat category does not demonstrate a defensible business.
