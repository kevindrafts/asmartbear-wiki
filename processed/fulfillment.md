# Finding Fulfillment

[Read Jason Cohen’s original](https://longform.asmartbear.com/fulfillment/) · Unofficial editorial note.

Cohen's diagram places fulfilling work where enjoyment, competence, and organizational need overlap. Missing need produces absorbing but unimportant work; missing competence produces enthusiastic underperformance; missing enjoyment can make valuable, skilled work exhausting. He used this analysis to move from CEO to CTO, rather than treating a title as the definition of success.

**Apply it:** Map current responsibilities against all three dimensions, then redesign roles or find complementary colleagues where a mismatch persists.

**Boundary:** Cohen distinguishes this framework from broader motivation theories: it assumes founder autonomy and treats need more tactically than purpose. It is a reflection tool, not a diagnosis. The official linked workshops extend the exercise.
