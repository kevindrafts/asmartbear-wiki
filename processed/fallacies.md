# The Serengeti Plain: Fallacies that aren’t fallacies

[Read Jason Cohen’s original](https://longform.asmartbear.com/fallacies/) · Unofficial editorial note.

Cohen challenges the habit of labeling every departure from a simple economic model irrational. Losing a lifetime's savings is different from losing a tiny experimental budget; attachment, consistency, and perseverance can have real value. He likewise defends selective convention-following and using incomplete information when delay is costly.

**Apply it:** Examine the stakes, reversibility, emotional value, and operating context before applying a bias label.

**Boundary:** This is a deliberately contrarian argument, not evidence that biases disappear. Expected monetary value is not the same as expected utility, and a useful commitment can still become denial. Cohen explicitly pairs confidence in direction with skepticism about details.
