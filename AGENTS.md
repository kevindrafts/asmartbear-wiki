# Repository rules

This is an unofficial commentary wiki, not an archive of Jason Cohen's writing.
Keep all fetched source HTML, extracted bodies, and source images exclusively in
`/Users/mordecai/.hermes/data/jason-cohen-source-cache` (or an explicitly configured external cache).
Never add them to Git, fixtures, build output, or search indexes. Use synthetic test fixtures.
Only original concise notes and synthesis may enter `processed/` and `wiki/`.
Link every article and substantive synthesis claim to its primary source.
Preserve qualifications, distinguish editorial inference, and do not write notes from titles.
Do not request source JSON endpoints or `/ref/`; honor robots and crawl sequentially.
Update `reports/build-status.md` after each batch. Run tests and validators before publishing.
No scheduled updates. No changes outside this repository and its designated external cache.
